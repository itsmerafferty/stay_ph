## 🏗️ ARCHITECTURE HIGHLIGHTS

### Pattern: Clean Architecture + MVVM
```
Presentation Layer (Widgets/Screens)
         ↓
State Management Layer (Riverpod)
         ↓
Business Logic Layer (Repositories/Services)
         ↓
Data Layer (Models/Entities)
         ↓
External Backend (Supabase)
```

### Tech Stack
- **Frontend**: Flutter 3.0+ with Material Design 3
- **State**: Riverpod 2.4+ with code generation
- **Backend**: Supabase (PostgreSQL + Auth + Storage + Realtime)
- **Services**: Firebase, Google Maps, PayMongo, AdMob
- **Database**: 14 optimized tables with RLS
